# Mais Esperto que o Diabo — página de vendas

Projeto de landing page responsiva para o e-book **Mais Esperto que o Diabo**, de Napoleon Hill.

## Conteúdo
- `index.html`: página de vendas.
- `styles.css`: identidade visual cinematográfica em preto e dourado.
- `script.js`: configuração do checkout Hotmart.
- `assets/capa-destaque.svg`: arte vetorial de destaque para o site.
- `assets/divulgacao-hotmart.svg`: arte vetorial de divulgação.

## Checkout
O botão principal direciona para:
https://pay.hotmart.com/Q107892470J

## Publicação
Abra `index.html` ou publique a pasta em uma hospedagem estática. Mantenha a pasta `assets` junto dos arquivos.

## Antes de anunciar
- Use apenas depoimentos reais, autorizados e verificáveis. A página não publica avaliações fictícias.
- Confirme no painel Hotmart preço, entrega, garantia e condições vigentes.
- Confirme que a licença/autorização cobre a edição e os materiais que serão comercializados.
